# SkillUp

SIH26134 — Skill development and industry demand alignment platform.

## Stack

- Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- Spring Security + JWT
- HTML / CSS / JavaScript
- Python for data processing and intelligence

## Structure

- `backend/` — Spring Boot REST API
- `frontend/` — Web frontend
- `data/` — Dataset and seed data
- `intelligence/` — Python data processing / intelligence
- `docs/` — Project documentation
